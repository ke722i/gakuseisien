#学生支援.com

## GitHub運用ルール（簡易版）

このREADMEでは、次の3つの書き方を統一する。

1. VS Codeでのコミット
2. GitHubでのPR作成
3. PM/SVのコミット

### 共通ルール

- 日付は `yy/MM/dd` 形式（例: `26/06/16`）
- 変更内容は英語で記載
- 説明では日本語で変更内容を記載

## 1. VS Codeコミット

形式:yy/MM/dd 英語で変更内容を記載

例:`26/06/16 adjust text form`

`テキストフォームを適用しました。`

## 2. PRタイトル・説明

### PRタイトル

`yy/MM/dd 英語で変更内容を記載`

例:`26/06/16 adjust text form`


### PR説明（本文）

以下を必ず書く。

1. 変更内容(日本語で簡素に記載する)

テンプレート

```
変更内容: テキストフォームを適用しました
```

## 3. PM/SVコミット

形式:yy/MM/dd 承認者名

詳細には、実施内容・確認結果・対象を記載する。

例:`26/06/16 Mise`

`動作確認済み feature01`
