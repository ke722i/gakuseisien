# アカウント運用と動作確認用アカウント

## 1. 他のメンバーが最新の状態にする手順

このブランチを取り込んだら、次の2つを実行してください。

```bash
php artisan migrate
php artisan db:seed
```

- `migrate` … `users.must_change_password` 列などが追加されます。
- `db:seed` … 動作確認用アカウントのプロフィール（学籍番号・クラス・氏名・担任）が入ります。
  `updateOrCreate` を使っているため、**何度実行しても重複せず**、既存アカウントも最新の内容に更新されます。

## 2. アカウントの運用方針

学生が自分でアカウントを作る方式は廃止しました。理由は次のとおりです。

- 欠席届は「担任のクラス番号（前方4文字）」で振り分けるため、学生がクラスを打ち間違えると**担任に届かない**
- 受理・差し戻しの通知は学籍番号で本人を特定するため、番号が誤っていると**通知が届かない**
- メール認証がないため、他人の学籍番号を騙って登録できてしまう

そのため、**教職員が名簿（CSV）を取り込んでアカウントを一括発行する方式**にしています。

| 項目 | 方針 |
|---|---|
| ログインID | **学籍番号**（本人が確実に覚えており、重複しない） |
| 初期パスワード | **ランダム**（英小文字6文字＋数字2桁）。法則性のあるものは同級生に推測されるため使わない |
| 初回ログイン | パスワード変更が**必須**（変更するまで他の画面は開けない） |
| パスワードを忘れた場合 | 教職員がアカウント管理画面から初期化（発行された新パスワードは画面に1度だけ表示） |

### CSVの形式

1行目の見出しは自動で読み飛ばします。列の順番は次のとおりです。

```csv
学籍番号,氏名,クラス番号,担任教師
234201,山田 太郎,R4SA24,片山 誠
234202,佐藤 花子,R4SA24,片山 誠
```

- 既に登録済みの学籍番号は**スキップ**され、既存アカウントは上書きされません。
- 学籍番号や氏名が空の行は取り込まれず、画面に理由が表示されます。
- Excelで保存した SJIS のCSVでも読み込めます。

取り込み後、**初期パスワード一覧をCSVでダウンロード**できます。パスワードは暗号化して保存されるため、
この画面を離れると再表示できません。必ずダウンロードして配布してください。

## 4. 欠席届の自動入力

学籍番号・クラス番号・氏名・担任教師は、ログイン中のアカウント情報から**自動入力**されます（変更不可）。

なりすまし防止のため、これらの項目は画面から送られた値ではなく、**サーバー側でログイン中のアカウントの値を使って保存**しています。
学籍番号やクラス番号が未登録のアカウントは、届を提出しようとすると担任へ登録を依頼する案内が表示されます。
